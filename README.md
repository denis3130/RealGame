# Mossbound

Roguelite in stile Archero per telefono, tutto in un solo file: `index.html`.

**Per giocare:** apri `index.html` nel browser (anche sul telefono).

**Per lavorarci con Claude Code:** apri Claude Code in questa cartella. Le regole del progetto, la mappa del codice e la lista delle cose da fare sono in `CLAUDE.md`.

**Test automatici:** `npm install`, poi `npx playwright install chromium`, poi ad esempio `npm run test:meta`. Dettagli in `CLAUDE.md`.
